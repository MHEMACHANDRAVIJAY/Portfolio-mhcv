# Grade Cards Directory

This folder contains semester grade card files for the Education page viewer.

## Instructions

1. Add your grade card files here (PDF or images)
2. Name them clearly: `sem1.pdf`, `sem2.pdf`, etc.
3. Update the file paths in `src/pages/Education.jsx`

## Example File Structure

```
grades/
├── sem1.pdf
├── sem2.pdf
├── sem3.pdf
├── sem4.pdf
├── sem5.pdf
├── sem6.pdf
├── sem7.pdf
└── sem8.pdf
```

## Supported Formats
- PDF (recommended)
- JPG/JPEG
- PNG
- WebP

## File Size
Keep files under 5MB for optimal loading speed.

## Privacy Note
Files in this public folder are accessible to anyone who visits your portfolio.
For sensitive documents, consider:
- Password-protected PDFs
- Watermarking
- Using authenticated cloud storage
