## 🎯 How to Upload Grade Cards

### Step 1: Navigate
Go to **Education Page** → Scroll to **B.Tech Card** → Find **"Academic Record Registry"**

### Step 2: Upload
Click **"Upload Card"** on any semester → Upload modal opens

### Step 3: Add File
**Drag and drop** your file OR **click to browse**

### Step 4: Wait
Progress bar shows upload (instant, client-side)

### Step 5: Done!
- Card status changes to **"Uploaded" ✅**
- Button changes to **"View Card"**
- File saved to localStorage automatically

---

## 👁️ How to View Grade Cards

1. Click **"View Card"** on uploaded semester
2. Viewer opens with your document
3. Use controls:
   - **[-]** Zoom Out
   - **[+]** Zoom In
   - **[⛶]** Fullscreen
   - **[X]** Close
4. Click outside or X to close

## 🔧 Quick Tips

### Best Practices
1. **Use PDF** for best quality
2. **Keep files under 5MB** for fast loading
3. **Name files clearly** before uploading
4. **Upload in order** (Sem 1, 2, 3...)

### If Something Goes Wrong
1. **Refresh the page** - Data persists
2. **Check file type** - Must be PDF/PNG/JPG
3. **Check file size** - Must be < 10MB
4. **Clear localStorage** if needed (starts fresh)
